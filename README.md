# Предсказание стоимости подержанных автомобилей

Учебный проект по регрессии: EDA, подготовка данных, обучение и сравнение OLS, Ridge и дерева решений, подбор параметров и проверка гипотез.

[Открыть исследование](research.ipynb) · [Открыть в Google Colab](https://colab.research.google.com/github/egorbolshanin/postupashki1/blob/main/research.ipynb)

## Датасет и задача

Выбран Used Car Prices: предсказываем `price` в долларах по характеристикам автомобиля.

Я сам занимался перепродажей автомобилей, поэтому выбрал этот датасет. Мне было интересно посмотреть, как методы машинного обучения оценивают стоимость автомобилей по их характеристикам, и сопоставить этот подход со своим практическим опытом.

В репозитории находится [used_cars.csv](used_cars.csv): **4 009 строк, 12 исходных столбцов**. Пробег `milage` измеряется в милях; название сохранено из CSV. Использован приложенный файл, поэтому все выводы относятся именно к этим 4 009 объявлениям.

[Страница датасета из задания](https://www.kaggle.com/datasets/taeefnajib/used-car-price-prediction-dataset).

## Исходные гипотезы

Список был зафиксирован после первичного знакомства со структурой данных, до подробного EDA и обучения:

1. **OLS покажет меньшую MAE, чем дерево решений.** Предполагаем, что зависимости цены от характеристик автомобиля достаточно хорошо описываются линейной моделью.
2. **Ridge с подобранным `alpha` покажет меньшую MAE, чем OLS.** Предполагаем, что регуляризация поможет справиться с мультиколлинеарностью признаков.
3. **Исключение одного из сильно коррелирующих признаков (`|r| > 0.7`) незначительно изменит качество модели прогнозирования цены автомобиля.**
4. **Совместное исключение `accident`, `model_year` и `clean_title` незначительно изменит качество предсказания цены**, несмотря на важность этих характеристик при покупке автомобиля.
5. **При глубине дерева больше 5 начнётся переобучение:** обучающая MAE будет уменьшаться, а средняя валидационная MAE — увеличиваться.
6. **Ridge на логарифме цены покажет меньшую MAE, чем Ridge на исходной цене.** Перед оценкой прогнозы преобразуются обратно в доллары.

## Проведение исследования

- Разделение: 3 207 обучающих и 802 отложенных тестовых наблюдения, `test_size=0.2`, `random_state=142`. EDA проводится на обучающей части. Дисбаланс классов не рассматривается: задача регрессионная.
- Обработка: числовые цена и пробег; нормализация пропусков; извлечение мощности и объёма двигателя, типа трансмиссии и числа передач. Все цвета сохранены отдельными категориями.
- В Pipeline: медианное заполнение числовых пропусков с индикаторами, `StandardScaler`, `OneHotEncoder(handle_unknown='ignore')`. Эти преобразования обучаются внутри каждого фолда.
- Оценивание: `KFold(n_splits=5, shuffle=True, random_state=142)`; основная метрика **MAE**, дополнительные **RMSE** и **R²**. MAE/RMSE считаются в долларах, в том числе после обратного преобразования логарифмированной цены.
- `GridSearchCV`: `alpha` для Ridge из `[0.01, 0.1, 1, 10, 100, 1000]`, глубина дерева из `[2, 3, 5, 7, 10, None]`. Обе версии Ridge выбрали `alpha=0.1`, дерево — `max_depth=None`.
- Отбор признаков: сравнение полных моделей с исключением группы из трёх признаков и исключением пробега из коррелирующей пары. Качество ухудшилось, поэтому сокращённые наборы отклонены. В этих опытах `alpha=0.1` фиксирована.

## Результаты

### Кросс-валидация

Средние по пяти валидационным фолдам. Значения ниже получены полным последовательным запуском `research.ipynb` 10.11.2026; машиночитаемая таблица — [results.csv](results.csv). Это **CV-оценки, а не результаты на отложенном тесте**.

| Вариант | Val MAE, $ | Val RMSE, $ | Val R² |
| --- | ---: | ---: | ---: |
| OLS | 18 609.21 | 77 094.91 | -0.14 |
| Ridge | 17 518.73 | 75 247.77 | -0.06 |
| Ridge с логарифмом цены | 11 013.35 | 61 970.40 | 0.45 |
| Дерево решений | 15 023.23 | 66 950.45 | 0.32 |
| Ridge log без трёх признаков | 13 614.64 | 64 154.75 | 0.40 |
| Ridge log без milage | 12 449.88 | 63 125.28 | 0.42 |

Лучший вариант по средней Val MAE — **Ridge с логарифмом цены, `alpha=0.1`, полный набор признаков**. Логарифмирование снизило MAE относительно обычной Ridge на 37.1%, RMSE — на 17.6%.

### Отложенный тест

После выбора моделей и настроек по CV каждая модель обучена через `.fit(X_train, y_train)` на всех 3 207 обучающих автомобилях и один раз оценена на 802 отложенных. В финальное сравнение вошли OLS, Ridge с логарифмом цены (`alpha=0.1`) и дерево (`max_depth=None`). Полный набор признаков сохранён. Параметры по тесту не подбирались.

| Модель | Test MAE, $ | Test RMSE, $ | Test R² |
| --- | ---: | ---: | ---: |
| OLS | 14 269.54 | 29 340.80 | 0.66 |
| Ridge с логарифмом цены | 8 958.65 | 28 977.46 | 0.67 |
| Дерево решений | 12 547.40 | 32 746.31 | 0.57 |

На отложенном тесте лучший результат среди трёх моделей получила выбранная по CV **Ridge с логарифмом цены**: MAE = **8 959 $**, RMSE = **28 977 $**, R² = **0.67**. У дерева Test MAE = 12 547 $, у OLS — 14 270 $. Результат поддерживает выбор Ridge по кросс-валидации. Дерево сохраняет нулевую ошибку на обучении и заметную ошибку на тесте. Параметры и признаки после просмотра тестовых результатов не изменялись.

Полные Train/Test метрики сохранены в [test_results.csv](test_results.csv).
